# CorpBrain MVP - 화면 단계별 프로세스 (UI Flow)

PRD v0.8 명세를 바탕으로 사용자가 앱을 실행하고 최종 위키 결과물을 얻기까지의 화면(Screen) 전환 흐름을 정리한 프로세스입니다.

---

## 🖥️ Screen 1: 웰컴 및 환경 설정 (Onboarding & Settings)
**앱을 처음 실행했을 때 맞이하는 기본 화면입니다.**

1. **AI 엔진 선택 (Option A vs B):** 
   - [A] 클라우드 API (OpenAI 등) 선택 시 -> API Key 입력 폼 활성화
   - [B] 로컬 LLM (Ollama) 선택 시 -> 백그라운드 Health Check (Ping) 실행
2. **Ollama 자동 온보딩 (Option B 선택 시 예외 흐름):**
   - 핑 실패 시 팝업: *"로컬 AI 구동을 위한 필수 엔진이 설치되어 있지 않습니다. 지금 설치하시겠습니까?"*
   - [설치 및 다운로드] 버튼 클릭 시 -> 진행률(Progress Bar) 표시와 함께 백그라운드 설치 및 `llama3` 모델 Pull 진행.

## 🖥️ Screen 2: 로컬 폴더 스캔 및 범위 선택 (Directory Selection)
**분석할 대상(Target)을 지정하는 화면입니다.**

1. **루트 폴더 지정:** [폴더 열기] 버튼으로 탐색기를 띄워 분석할 최상위 폴더 선택.
2. **비동기 스캔 진행률:** UI가 멈추지 않고 상단에 "파일 스캔 중... (N개 완료)" 텍스트가 0.5초 간격으로 갱신됨.
   - *예외 알림:* 1만 개 초과 시 [일시 중지 팝업], 경로 초과/권한 거부 파일은 스캔 후 하단 [토스트 알림]으로 "N개 파일 스킵됨" 표시.
3. **트리 뷰(Tree View) 시각화:** 좌측 패널에 폴더 구조가 펼쳐짐. 
   - 문서 포맷(`.docx`, `.pdf`, `.txt`)만 필터링되어 보임.
   - 사용자가 불필요한 폴더/파일의 체크박스(☑️)를 해제하여 분석 범위 튜닝.

## 🖥️ Screen 3: 분석 모드 선택 및 실행 (Analysis Execution)
**스캔된 대상들을 어떻게 요리할지 결정하는 화면입니다.**

1. **모드 선택 라디오 버튼:**
   - ⚡ **고속 분석 (파일명 위주):** 빠르게 파악하고 싶을 때.
   - 🧠 **심층 분석 (위키 생성):** 내용을 모두 읽고 구조화된 지식을 원할 때.
2. **실행 및 상태 모니터링:** 
   - [분석 시작] 버튼 클릭.
   - 로컬 DB 캐시를 대조(`last_modified` 비교)하여 중복 파싱 스킵.
   - 중앙에 큰 **Progress Bar** 노출: `[파싱 중...] -> [로컬 캐시 저장 중...] -> [AI 추론 중...]`
   - [일시 정지(Pause) / 취소] 버튼 제공.

## 🖥️ Screen 4: 결과 리뷰 및 일괄 변경 (Result & Batch Rename)
**AI가 분석한 결과를 확인하고, 무질서한 파일명을 정리하는 화면입니다.**

1. **(고속 분석 시) 파일 중요도 맵:**
   - 기존의 Tree View 우측에 AI가 생성한 '1줄 요약 라벨'과 '중요도 별점(⭐)'이 붙어서 나열됨.
2. **일괄 변경(Rename) 제안 (Diff 뷰):**
   - 화면 하단 또는 우측 패널에 표(Table) 형태로 **[기존 파일명] ➔ [AI 추천 파일명]** 리스트가 노출됨.
   - 추천 파일명은 `[260714]_CorpBrain_기획서_01.docx` 등 템플릿 적용.
   - 사용자가 리스트를 검토 후 [승인 후 일괄 변경] 버튼 클릭 -> OS 파일명 실제 변경.
3. **실행 취소 (Undo):**
   - 파일명 변경 후, 언제든 [되돌리기(Undo)] 버튼을 눌러 이전 상태로 100% 원복 가능.

## 🖥️ Screen 5: 완성된 지식 위키 뷰어 (Wiki & Fact-check)
**심층 분석 완료 시 떨어지는 최종 산출물(Markdown)을 보는 화면입니다.**

1. **노션 스타일 Rich Text 뷰어:** AI가 생성한 프로젝트 구조화 위키(Markdown)가 화면 중앙에 렌더링됨.
2. **로컬 딥링크(Trust-Anchor):** 
   - 위키 본문 중간중간에 `[문서 원문 열기]` 형태의 파란색 하이퍼링크가 존재.
   - 클릭 시 -> 윈도우 OS의 기본 연결 프로그램(MS Word, PDF 뷰어 등)이 팝업되며 원본 문서가 띄워짐 (팩트체크 용이).
3. **내보내기 (Export):** [복사하기] 또는 [.md 파일로 저장] 버튼을 통해 외부 툴(노션, 컨플루언스)로 이관 지원.
