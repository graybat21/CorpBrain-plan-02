# CorpBrain Value Proposition Sheet (Part 1)
> **대상 독자**: 처음으로 본격적인 신규 B2B SaaS 사업을 기획하는 예비 창업자 (대표님)
> **작성 목적**: 우리가 타겟하는 핵심 고객의 문제(Problem)와 우리의 해결책(Solution)이 시장에서 어떻게 연결되며, 어떤 차별적 가치를 지니는지(Problem-Solution Fit)를 한눈에 파악할 수 있도록 구성했습니다.

---

## 1. Value Proposition Sheet (Problem–Solution Fit)

본 섹션은 앞선 문서들(페르소나 분석, 고객 여정 지도, JTBD 심층 인터뷰 등)을 종합하여, 고객이 겪는 고통(Pain)이 우리의 핵심 제안(Value Proposition)으로 어떻게 해소되는지 직관적으로 매핑한 표입니다. 대표님께서 투자자(VC)나 초기 팀원들에게 우리 비즈니스의 존재 이유를 설명하실 때 가장 뼈대가 되는 자료입니다.

### 1-1. 핵심 사용자 (Core) : "파편화 융합형 실무자" 이수아 (PM)
**타겟 세그먼트**: Q1 혁신적 IT 스타트업 실무진 (가장 먼저 지갑을 여는 얼리어답터)

| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain, Needs)** | - 슬랙, 지라, 노션 등 여러 툴에 정보가 파편화되어 있어, 이를 하나로 묶기 위해 매일 1~2시간씩 **'수동 문서화 노동'**에 시달림.<br>- 새로운 툴(SaaS)을 도입하면 또 하나의 관리 포인트가 생기므로 **새로운 툴 학습에 대한 강한 저항감** 존재. |
| **목표 서술 (Goal, Job)** | - *JTBD:* 내가 기존 툴(슬랙, 지라) 화면을 벗어나지 않고도, AI가 알아서 논의 맥락을 병합해 초안을 제공해 주어 **'버튼 클릭 한 번'**으로 문서화를 끝내고자 함. |
| **고객이 원하는 Outcome** | - **매일 1~2시간 소요되던 문서화 시간을 퇴근 전 10분 이내로 극단적 단축.**<br>- 파편화에 따른 정보 누락률 0% 달성. |
| **우리 솔루션의 핵심 제안<br>(Value Proposition)** | - **마찰 제로 초자동화 수집기 (Zero-UI Collector)**: 새로운 창을 띄울 필요 없이 백그라운드에서 이기종 데이터를 시맨틱 융합하여 초안 자동 생성. |
| **기존 대안 (Competitor / Substitute)** | - 노션(Notion) 타임라인 수동 정리<br>- 슬랙 자체 검색 및 단순 복붙<br>- 기존의 단순 데이터 포워딩 자동화 툴 (예: Zapier) |
| **차별적 가치** | - **"100% 원본 딥링크 추적 보장"**: 단순 텍스트 생성을 넘어 생성된 요약문 옆에 항상 원본 링크를 매핑하여 **AI 환각(Hallucination)에 대한 공포를 완벽히 불식(신뢰의 안전망 제공)**. |
| **Proof (근거 / 검증 데이터)** | - *AOS 4.0 / DOS 3.6 (최상위 기회 지표)*: Zero-UI와 환각 방어 기능은 실무자의 가장 강력한 페인포인트를 해결하며 솔루션 잔존율(Retention)을 좌우함. |

### 1-2. 확장 사용자 (Adjacent) : "B2B 도입 검토자" 강서연 (DX 팀장)
**타겟 세그먼트**: Q2 실용적 탐색자 (엔터프라이즈 확장을 위한 1차 관문이자 결재권자)

| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain, Needs)** | - 사내 사일로 현상을 해결하고 싶으나, 외부 SaaS 서버에 기밀 데이터를 넘기는 것에 대해 **경영진의 극심한 반대**에 부딪힘.<br>- 도입 비용에 대한 뚜렷한 **투자 대비 효용(ROI) 증명**이 어려워 결재 반려 가능성이 높음. |
| **목표 서술 (Goal, Job)** | - *JTBD:* 경영진의 기밀 반출 우려를 완벽히 차단하고, 절감된 인건비를 숫자로 보여주어 한 번에 솔루션 도입 승인을 받아내고자 함. |
| **고객이 원하는 Outcome** | - **기밀 데이터 유출 사고 발생률 0%.**<br>- 솔루션 도입 후 월/분기별 명확한 ROI(인건비 절감) 지표 확보. |
| **우리 솔루션의 핵심 제안<br>(Value Proposition)** | - **경영진 결재 프리패스 무기**: 강력한 기밀 마스킹 파이프라인(데이터 난독화)과 대시보드 내 자동 ROI(비용 절감) 산출 리포트 탑재. |
| **기존 대안 (Competitor / Substitute)** | - 구형 사내망 그룹웨어 게시판 (비용과 보안 이유로 억지 유지)<br>- 무거운 엔터프라이즈급 온프레미스(On-Premise) 시스템 |
| **차별적 가치** | - AI의 혁신성은 취하면서도 **엔터프라이즈급 보안 통제권(RBAC 및 마스킹)**을 스타트업 툴 레벨에서 기본 제공하여 결재 허들을 즉시 낮춤. |
| **Proof (근거 / 검증 데이터)** | - *AOS 3.0 / DOS 2.4 (높은 중요도)*: 보안과 명분 없이는 실무자(C1)가 아무리 원해도 라이선스 갱신 및 전사 확장이 불가능하다는 것이 심층 인터뷰에서 입증됨. |

### 1-3. 극단 사용자 (Extreme) : "멀티호밍 한계 시험자" 한유리 (에이전시 PM)
**타겟 세그먼트**: Q4 극단 변형 (시스템 엔진 한계의 기준점)

| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain, Needs)** | - 10개 이상의 툴(클라이언트 요구사항)이 동시다발적으로 쏟아지는 극단적 파편화 속에서, 정보 누락 시 위약금 등 돌이킬 수 없는 피해 발생에 대한 **패닉과 강박**. |
| **목표 서술 (Goal, Job)** | - *JTBD:* 수많은 채널의 복잡한 맥락이 꼬임 없이 하나의 타임라인으로 정확히 **시맨틱 융합**되는 것을 보고 싶음. |
| **고객이 원하는 Outcome** | - 다중 채널 환경에서 환각 및 정보 누락으로 인한 컴플레인 제로화. |
| **우리 솔루션의 핵심 제안<br>(Value Proposition)** | - **직관적 HITL(Human-In-The-Loop) 피드백 루프**: 엣지 케이스에서 AI가 혼동할 경우, 사용자가 가벼운 승인/수정 클릭을 통해 AI 엔진을 즉각 교정하고 재학습시키는 권한 제공. |
| **기존 대안 (Competitor / Substitute)** | - 엑셀 및 수첩에 강박적 타임라인 수기 기록. |
| **차별적 가치** | - **"인간과 AI의 완벽한 협업(Copilot) 구조"**: 완전 자동화를 맹신하지 않고, 최종 통제권(교정 권한)을 사용자에게 넘겨 AI 오류로 인한 파국적 리스크를 사용자 주도적으로 제어. |
| **Proof (근거 / 검증 데이터)** | - 극단적 환경(10개 채널)에서도 버티는 엔진 신뢰성 검증은 일반 타겟(C1)에게 제공하는 무결성의 보증수표가 됨. (AOS 4.0 / DOS 2.8) |

| 우선순위 | 핵심 기능 (Feature) | 대상 페르소나 | 개발 목표 및 기댓값 | 시장 기회 (AOS/DOS) |
| --- | --- | --- | --- | --- |

| **1순위<br>(Must Have)** | **엔터프라이즈급 기밀 마스킹 파이프라인** | A1 (DX팀장) | 주요 기밀/주민번호 마스킹 후 서버 전송.<br>경영진의 B2B 도입 반려 사유 1순위 제거. | High / High<br>(AOS 4.0 / DOS 3.6) |

## 3. 예비 창업자(Founder)를 위한 전략적 체크포인트

신규 사업을 처음 기획하시는 대표님을 위해, 본 Value Proposition Sheet를 실무에 어떻게 활용해야 하는지 핵심 가이드를 추가로 제안합니다.

1. **절대 '모든 기능'을 한 번에 개발하지 마세요.**
   - 초기 제품(MVP)은 위 표의 **'1순위(Must Have)' 3가지**만 완벽하게 동작하면 시장에 나갈 수 있습니다. 대시보드가 예쁘지 않더라도 "알아서 백그라운드에서 수집되고, 요약이 팩트 기반(원본 링크)이며, 기밀이 유출되지 않는다"는 핵심 가치만 증명하면 얼리어답터(C1)는 지갑을 엽니다.
2. **세일즈 피칭의 무게 중심을 분리하세요.**
   - **실무자(C1) 미팅 시**: 철저하게 **"당신의 퇴근 시간을 얼마나 단축시켜주는가(Zero-UI)"**에 집중하십시오.
   - **결재권자(A1) 미팅 시**: 혁신성이 아니라 **"어떻게 내부 정보 유출을 막아내고(마스킹), 이 툴이 월 얼마의 비용을 아껴주는지(ROI 리포트)"**에 집중하십시오.
3. **'AI의 완벽함'을 팔지 말고 '인간과의 협력(HITL)'을 파십시오.**
   - 극단적 파편화를 겪는 고객(E1)조차도 AI가 한 번에 완벽할 것이라 기대하지 않습니다. 틀려도 좋으니 **원본으로 돌아갈 수 있는 링크**가 있고, **내가 직관적으로 고쳐줄 수 있는 UI**가 있다면 안심하고 사용합니다.
4. **당장 규제 벽에 부딪히는 고객(N1)은 과감히 버리십시오.**
   - 금융/의료 등 클라우드 반출 자체가 불법인 시장에 MVP를 맞추려다 보면 SaaS의 본질을 잃게 됩니다. 이들은 다음 투자 라운드(Series A 이상)에서 On-Premise 아키텍처를 구축할 때 공략할 타겟입니다.
