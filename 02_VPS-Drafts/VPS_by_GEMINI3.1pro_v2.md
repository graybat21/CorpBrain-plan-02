# CorpBrain Value Proposition Sheet (v2)

> **대상 독자**: 처음으로 본격적인 신규 B2B SaaS 사업을 기획하는 예비 창업자 (대표님)
> **작성 목적**: 타겟 고객의 문제와 해결책의 핏(Problem-Solution Fit)을 검증하고, 수익성과 지속 가능한 성장 구조를 담은 포괄적 가치 제안서입니다.

---

## 1. Pain–Solution–Outcome 핵심 흐름 정리

비즈니스의 복잡한 로직을 투자자와 고객에게 1분 안에 설명할 수 있는 직관적인 가치 흐름입니다.

| 단계 | 실무자 (C1: 이수아 PM) | 결재권자 (A1: 강서연 팀장) | 극한 환경 유저 (E1: 한유리 PM) |
| --- | --- | --- | --- |
| **Pain (고통)** | 수많은 툴(슬랙, 지라) 파편화로 매일 1~2시간씩 수동 문서화 노동에 시달림. | AI 도입 시 기밀 유출 반대, 확실한 비용 절감(ROI) 명분 부재. | 10개 이상 툴 파편화로 인한 패닉, 정보 누락 시 돌이킬 수 없는 위약금 리스크. |
| **Solution (해결책)** | **Zero-UI 백그라운드 수집기**: 평소처럼 일하면 알아서 초안 병합. | **엔터프라이즈급 마스킹 파이프라인** 및 ROI 시각화 대시보드 탑재. | **100% 원본 딥링크 매핑** 및 교정 가능한 직관적 HITL 피드백 루프. |
| **Outcome (원하는 결과)** | 퇴근 전 10분, 원클릭 승인으로 **문서화 시간 90% 극단적 단축**. | 기밀 유출 0%, 경영진 보고 시 **명확한 인건비 절감 성과 증명**. | 다중 채널 환경에서도 **오류/환각 없는 정보 병합, 클라이언트 컴플레인 제로**. |

## 2. Value Proposition Sheet (Problem–Solution Fit)

페르소나별 심층 니즈와 CorpBrain이 제공하는 차별적 가치를 상세히 매핑한 핵심 뼈대입니다.

### 2-1. 핵심 사용자 (Core) : "파편화 융합형 실무자" 이수아 (PM)
| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain)** | - 여러 툴에 정보가 분산되어 이를 하나로 묶기 위해 매일 1~2시간씩 수동 문서화에 시달림.<br>- 새로운 SaaS 학습에 대한 강한 저항감 존재. |
| **목표 서술 (Goal, Job)** | - 기존 툴 화면을 벗어나지 않고도, AI가 논의 맥락을 병합해 주어 '버튼 클릭 한 번'으로 문서화를 끝내고자 함. |
| **고객이 원하는 Outcome**| - 문서화 시간을 퇴근 전 10분 이내로 극단적 단축, 파편화에 따른 정보 누락 0%. |
| **우리 솔루션의 핵심 제안** | - **마찰 제로 초자동화 수집기 (Zero-UI Collector)**: 백그라운드에서 이기종 데이터를 시맨틱 융합. |
| **기존 대안 (Competitor)** | - 노션 타임라인 수동 정리, 메신저 단순 검색, Zapier 단순 포워딩 |
| **차별적 가치** | - **"100% 원본 딥링크 추적 보장"**: 요약문 옆에 원본 링크를 매핑하여 AI 환각(Hallucination) 공포를 불식. |
| **Proof (검증 데이터)** | - *AOS 4.0 / DOS 3.6 (최상위 지표)*: Zero-UI와 환각 방어는 실무자의 핵심 페인포인트를 해결하며 리텐션을 좌우함. |

### 2-2. 확장 사용자 (Adjacent) : "B2B 도입 검토자" 강서연 (DX 팀장)
| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain)** | - AI 솔루션 도입 시 경영진의 극심한 보안/기밀 유출 우려 및 투자 대비 효용(ROI) 증명 난항. |
| **목표 서술 (Goal, Job)** | - 기밀 반출 우려를 차단하고, 절감된 인건비를 숫자로 보여주어 한 번에 도입 승인을 받아내고자 함. |
| **고객이 원하는 Outcome**| - 기밀 유출 0%, 솔루션 도입 후 명확한 ROI 지표 확보. |
| **우리 솔루션의 핵심 제안** | - **경영진 결재 프리패스 무기**: 강력한 기밀 마스킹 파이프라인과 대시보드 내 ROI 산출 리포트 탑재. |
| **차별적 가치** | - 혁신성을 취하면서도 엔터프라이즈급 보안 통제권(RBAC/마스킹)을 기본 제공하여 결재 허들을 즉시 낮춤. |

### 2-3. 극단 사용자 (Extreme) : "멀티호밍 한계 시험자" 한유리 (에이전시 PM)
| 항목 | 내용 |
| --- | --- |
| **핵심 문제 서술 (Pain)** | - 10개 이상의 툴에서 쏟아지는 극단적 파편화 속 정보 누락에 대한 패닉과 강박. |
| **우리 솔루션의 핵심 제안** | - **직관적 HITL 피드백 루프**: 엣지 케이스에서 사용자가 가벼운 승인/수정 클릭을 통해 AI 엔진을 교정. |
| **차별적 가치** | - **"인간과 AI의 완벽한 협업 구조"**: 최종 통제권을 사용자에게 넘겨 AI 오류로 인한 파국적 리스크 통제. |

## 3. 수익구조 및 가격 정책 (Revenue Model & Pricing Strategy)

솔루션의 장기적 성장성과 지속 가능성을 담보하기 위한 B2B SaaS 과금 모델 설계입니다. (단순 추정이 아닌 **실제 B2B SaaS 시장 단가 및 당사 TAM/SAM/SOM 산출 데이터**에 기반)

### 3-1. 현실 데이터 기반 벤치마크 및 지불 의향(WTP)
- **시장 검증 데이터 (경쟁/유사 B2B AI 솔루션 실제 과금 수준)**:
  - Notion AI: **$8~$10** / User / Month
  - Slack AI: **$10** / User / Month
  - GitHub Copilot: **$19** / User / Month
  - Glean (엔터프라이즈 통합 검색): **$40+** / User / Month (커스텀)
- **당사 초기 SOM 산출 데이터 (10인 미만 스타트업 타겟)**:
  - `6-10_CorpBrain_TAM_SAM_SOM_산출표.md`에 따르면, 기업당 연간 SaaS 문서화 툴 예산(WTP) 추정액은 약 **$1,300** 입니다.
  - 이를 10인 기준 월간으로 환산하면 **기업당 월 약 $108 (유저당 약 $10.8)** 로, 시장의 실제 B2B AI Add-on 지출액(약 $10 수준)과 정확히 일치합니다.

### 3-2. CorpBrain 가격 정책 제안 (Seat 기반 + Tiered Model)
이러한 현실 데이터를 바탕으로, 진입 장벽을 낮추고 확장 시 객단가(ARPU)를 높이는 **Tier별 구독 모델**을 적용합니다.

| 플랜명 | 과금액 (User/Month) | 타겟 페르소나 | 제공 가치 및 한계 | 전략적 목적 |
| --- | --- | --- | --- | --- |
| **Starter (기본형)** | **$12** | C1 (초기 도입 스타트업) | - 채널 연결 2개 제한 (슬랙, 지라)<br>- 월 1만 회 요약 생성 한도 | **빠른 시장 침투**: 10인 기업 기준 월 $120(연 $1,440)로 1차 산출된 SOM 지불 의향($1,300)과 부합. |
| **Pro (확장형)** | **$25** | A1 (DX팀장), E1 (다중 채널) | - 채널 무제한 연결<br>- 기밀 마스킹 파이프라인 (필수)<br>- ROI 증명 리포트 및 RBAC 통제 | **수익성 극대화 (Up-sell)**: 보안과 ROI 증명이 절실한 결재권자(A1)는 2배의 비용을 기꺼이 지불함. |
| **Enterprise** | **Custom ($50+)** | N1 (망분리 통제 CISO) | - On-Premise 및 BYOC 설치<br>- 완벽한 데이터 로컬 보관 보장 | **장기 성장성**: SaaS 한계를 넘어 금융/의료 등 고부가가치 시장(TAM 확장) 진입. |

### 3-3. 수익성 및 지속가능성 분석 (ROI 논리)
- **고객사 입장의 ROI (가치 입증)**:
  - 실무자(PM) 평균 월급 약 500만 원. 문서화 노동에 쏟는 시간(15%) = **기회비용 월 75만 원**.
  - CorpBrain Starter 도입(1인당 $12, 한화 약 1.6만 원)으로 월 75만 원의 노동을 절감. **(비용 대비 약 46배의 압도적 ROI 달성)**. 이는 A1(강서연)이 경영진을 설득하는 강력한 세일즈 덱이 됩니다.
- **솔루션의 지속성 (Lock-in 효과)**:
  - Zero-UI(백그라운드 수집) 구조는 사용자의 체감 마찰을 없애 **이탈률(Churn Rate)을 극단적으로 낮춥니다.**
  - 한 번 사내 위키와 프로젝트 히스토리가 CorpBrain에 축적되기 시작하면 **전환 비용(Switching Cost)**이 폭증하여 안정적인 월간 반복 수익(MRR) 창출이 가능합니다.

## 5. 예비 창업자(Founder)를 위한 전략적 체크포인트

신규 사업을 기획하시는 대표님을 위해, 본 문서를 실무와 세일즈에 어떻게 활용해야 하는지 제안합니다.

1. **절대 '모든 기능'을 한 번에 개발하지 마세요.**
   - 초기 제품(MVP)은 **'1순위(Must Have)' 3가지**만 동작하면 시장에 나갈 수 있습니다. 대시보드가 예쁘지 않더라도 "알아서 백그라운드에서 수집되고(Zero-UI), 원본 링크가 있으며, 기밀이 유출되지 않는다"만 증명하면 얼리어답터(C1)는 플랜을 결제합니다.
2. **세일즈 피칭의 무게 중심을 분리하세요.**
   - **실무자(C1) 대상**: 철저하게 **"당신의 퇴근 시간을 얼마나 단축시켜주는가(월 $12로 75만원의 가치)"**에 집중하십시오.
   - **결재권자(A1) 대상**: **"기밀 유출 걱정 없고(마스킹), 이 툴이 월 75만 원의 인건비를 아껴준다(ROI 리포트)"**는 경영진 설득 논리에 집중하십시오.
3. **규제 벽에 부딪히는 고객(N1)은 MVP 단계에서 과감히 버리십시오.**
   - 금융/의료 등 클라우드 반출 자체가 불법인 시장에 맞추려다 보면 SaaS의 본질을 잃게 됩니다. 이들은 향후 Series A 이상에서 Custom($50+) 과금 체계의 On-Premise 아키텍처 구축 시 공략할 장기 타겟입니다.
