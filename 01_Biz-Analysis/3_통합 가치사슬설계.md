# 📌 CorpBrain 통합 가치사슬 설계 (B+C+D Winning Mix)

## 1. 핵심 가치창출 전략 (Winning Mix)
CorpBrain은 단일 시장이 아닌 3개 시장의 강점을 결합하여 "10인 미만 기업용 자율 보안 지식 자산 시장"이라는 독점적 지위를 창출합니다.
* **[Market B] 자동 수집 (Input):** 카카오톡, 이메일 등에서 지식을 백그라운드로 자동 흡수하여 문서 작성 노동 자체를 완벽히 제거합니다 (Zero-Effort).
* **[Market D] 자율 위키 가드닝 (Process):** 수동 업데이트의 한계를 극복하기 위해, 자율 지식 구조화 엔진이 스스로 문서를 병합하고 위키 트리 구조로 자동 정리합니다.
* **[Market C] 어플라이언스 렌탈 (Output/Delivery):** 클라우드 SaaS의 보안 불안감을 원천 차단하기 위해, 기밀 유출 걱정 없는 물리적 하드웨어(온프레미스 워크스테이션) 형태로 배포합니다.

---

## 2. 주 활동 (Primary Activities) 설계
사용자의 개입 없이 지식이 흐르고 안전하게 저장되는 '자동화 파이프라인'을 구축합니다.

| 항목명 | 🏗️ B+C+D 융합 가치사슬 전략 |
| :--- | :--- |
| **투입/조달 물류**<br>(Inbound) | **[B시장 전략]** 사용자의 매뉴얼 업로드를 배제하고, Slack, 카카오톡, 이메일 등 사내 협업툴 API 연동을 통해 파편화된 지식을 백그라운드에서 자동 수집합니다. (※ 기초 파싱 기술(A시장)은 외부 오픈소스를 전적으로 차용하여 리소스를 절감합니다.) |
| **운영/생산**<br>(Operations) | **[D시장 전략]** 수집된 데이터를 자율 지식 구조화 엔진이 스캔하여, 폴더 구조 리팩터링 및 고립된 문서 연결을 자율 수행(지식 가드닝)합니다. 유사 문서의 타임스탬프를 대조해 변경점(Diff)과 충돌(Conflict)을 자동 관리합니다. |
| **산출/배송 물류**<br>(Outbound) | **[C시장 전략]** 퍼블릭 클라우드를 배제하고, 고객사 내부망에서만 폐쇄적으로 작동하는 물리적 GPU 워크스테이션(어플라이언스 턴키) 형태로 결과물(자율 위키)을 배포합니다. |
| **마케팅/영업**<br>(M&S) | 10인 미만 기업 대표를 대상으로 "퇴사 시 노하우 유실 방지"와 "완벽한 보안"을 소구합니다. 거액의 초기 장비 구매 비용을 없애기 위해 '정수기 렌탈 방식'의 하드웨어 월 과금 모델(BM 3)을 핵심 무기로 영업합니다. |
| **서비스**<br>(Service) | **[D시장 연계]** 사용자가 시스템의 병합 결과를 '승인/수정'하는 피드백 루프를 구축하고, 이를 즉시 RL 보상 함수(Reward Function)로 반영하여 자율 진화하는 A/S 체계를 만듭니다. 물리적 하드웨어(C시장) 장애 발생 시 현장 유지보수를 제공합니다. |

---

## 3. 지원 활동 (Support Activities) 설계
핵심 전략인 '자율 가드닝(D)'과 '하드웨어 배포(C)'를 뒷받침하기 위해 기업 역량을 집중합니다.

| 항목명 | 🏗️ B+C+D 융합 가치사슬 전략 |
| :--- | :--- |
| **기업 인프라** | MVP 단계에서는 매니지드 클라우드를 배제하고, 철저히 '온프레미스 어플라이언스 단일 배포 아키텍처'에 자원을 집중하여 보안 민감 고객을 선점합니다. |
| **인적 자원 관리** | AI 역량은 오픈소스(Gemma 등) 최적화와 자율 지식 구조화 엔진 기반 보상 모델 튜닝이 가능한 핵심 데이터 엔지니어에 집중 투자합니다. 기기 설치 및 출장 AS를 담당할 하드웨어 현장 인력망을 확보합니다. |
| **기술 개발** | 범용 파서 개발을 중단하고(Buy/Use), 백그라운드 수집을 위한 API 파이프라인 안정화 및 문서 내용의 미세한 충돌/병합 제어 알고리즘 R&D에 전력투구합니다. |
| **조달/구매** | 엣지급 GPU가 탑재된 고사양 워크스테이션을 안정적인 단가로 조달할 하드웨어 벤더 파트너십을 구축합니다. 안정적인 '월 렌탈 BM' 실현을 위해, 초기 구매 자본을 융통해 줄 B2B 리스/캐피탈 금융 제휴를 최우선으로 체결합니다. |
