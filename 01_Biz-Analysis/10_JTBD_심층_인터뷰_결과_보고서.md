## **1. JTBD 요약 카드 (Job Story)**

### **[수익 기여 1순위] C1 이수아 (Core - 파편화 융합형 실무자)**

| 구분 | 내용 |
| --- | --- |
| **Situation** | 프로젝트 마일스톤이 끝나고 여러 채널(슬랙, 지라)의 파편화된 히스토리를 노션에 취합해야 할 때 |
| **Job Statement** | 내가 기존 툴 화면을 벗어나지 않고도 AI가 논의 맥락을 알아서 병합한 초안을 제공해 주어, 승인 클릭 한 번으로 문서화를 끝내고자 함. |
| **Desired Outcome** | **매일 1~2시간 소요되던 수동 문서화 시간을 10분 이내로 극단적 단축, 정보 누락 0건** |
| **4 Forces** | **Push:** 매번 여러 툴을 오가며 복붙해야 하는 단순 노동의 극심한 피로감 / **Pull:** Zero-UI 백그라운드 수집과 '퇴근 전 승인 1회'라는 극강의 편의성<br>**Habit:** 울며 겨자 먹기로 노션에 수기로 타임라인을 정리하던 관성 / **Anxiety:** AI가 할루시네이션(환각)을 일으켜 엉뚱한 내용을 요약할까 봐 불안 |
| **Current / Barrier** | **솔루션:** 노션 타임라인 수동 정리, 메신저 수동 검색 / **장벽(Barrier):** AI 초안의 정확도를 100% 신뢰할 수 없음 |
| **Evidence / Priority** | *"요약본 읽다가 찜찜하면 바로 원본 가서 팩트체크가 되니까 안심입니다."* / **AOS 4.0 , DOS 3.6** |

### **[결재 허들 돌파 1순위] A1 강서연 (Adjacent - B2B 도입 검토자)**

| 구분 | 내용 |
| --- | --- |
| **Situation** | 조직 내 부서 간 사일로를 해결하기 위해 새로운 지식 관리 솔루션의 도입 기안을 결재 올려야 할 때 |
| **Job Statement** | 경영진의 기밀 반출 우려를 완벽히 차단하고, 절감된 인건비를 숫자로 보여주어 한 번에 도입 승인을 받아내고자 함. |
| **Desired Outcome** | **기밀 데이터 유출 사고 0%, 도입 후 명확한 ROI(비용 절감) 지표 확보** |
| **4 Forces** | **Push:** 과거 AI 툴 도입 시 경영진의 보안 우려로 반려된 경험 / **Pull:** 강력한 기밀 마스킹 아키텍처와 대시보드 내 ROI 자동 산출 리포트<br>**Habit:** 비용과 보안 문제로 레거시 게시판을 억지로 유지하는 보수적 관성 / **Anxiety:** 혹시 모를 내부 정보 유출 시 모든 책임을 져야 한다는 두려움 |
| **Current / Barrier** | **솔루션:** 기존 사내망 그룹웨어 / **장벽:** SaaS 형태의 외부 서버 전송 자체에 대한 경영진의 본능적 거부감 |
| **Evidence / Priority** | *"보안 유출 문제 없고, 월 OOO만 원의 인건비 절감 효과가 있다고 숫자로 보여줘야 결재가 수월해집니다."* / **AOS 3.0 , DOS 2.4** |

### **[엔진 신뢰성 1순위] E1 한유리 (Extreme - 멀티호밍 한계 시험자)**

| 구분 | 내용 |
| --- | --- |
| **Situation** | 슬랙, 잔디, 카톡 등 10개 이상의 채널에서 다수의 클라이언트 요청이 동시다발적으로 쏟아져 들어올 때 |
| **Job Statement** | 수많은 채널의 파편화된 맥락이 꼬임 없이 하나의 프로젝트 타임라인으로 정확히 시맨틱 융합되는 것을 보고 싶음. |
| **Desired Outcome** | **다중 채널 환경에서 환각 없는 정보 병합, 정보 누락으로 인한 위약금 및 컴플레인 제로화** |
| **4 Forces** | **Push:** 창 10개를 띄워놓고 수기로 관리하며 느끼는 패닉과 강박 / **Pull:** 직관적인 수동 교정(HITL) UI를 통해 AI가 내 의도를 즉시 학습하는 쾌감<br>**Habit:** 클라이언트가 요구하는 각기 다른 메신저를 무조건 맞춰줘야 하는 업계 관성 / **Anxiety:** 유사한 프로젝트명에서 AI가 내용을 섞어버리면 돌이킬 수 없는 사고 발생 |
| **Current / Barrier** | **솔루션:** 재피어(Zapier) 단순 포워딩, 엑셀 수기 관리 / **장벽:** 기존 자동화 툴은 시맨틱한 '맥락 융합'이 불가능함 |
| **Evidence / Priority** | *"교정(HITL)해 줬을 때 바로 학습해서 다음부터 안 틀린다면 충분히 감수할 수 있어요."* / **AOS 4.0 , DOS 2.8** |

## **3. 종합 결론 및 MVP 전략 제안**

**총 3인(C1, A1, E1)의 결정적 '전환 스위치'를 집중 분석한 결과, CorpBrain이 B2B 지식 관리 초기 시장에 진입하기 위한 유일한 PMF 전략은 철저히 숨어있는 'Zero-UI 마찰 제로화'와, 환각 및 기밀 유출을 완벽히 통제하는 '엔터프라이즈급 신뢰 구축'입니다.**

### **🚀 MVP (Phase 1) 생존을 위한 2대 핵심 제품 전략**

1. **마찰 제로 초자동화 수집기 (Zero-UI Collector - C1 최적화)**
    - **구현 목표:** 사용자가 새로운 솔루션 창을 띄울 필요 없이(Zero-UI) 백그라운드에서 지라/슬랙 데이터를 시맨틱하게 융합하고, 퇴근 전 확인할 '초안 승인 대시보드' 하나만 제공.
    - **전략 의미:** 기존 업무 워크플로우를 전혀 방해하지 않아 학습 장벽(Onboarding Friction)을 없애고, 실무자의 고질적인 "문서화 알바 시간"을 단 10분으로 극단적 단축시킵니다.
2. **환각/보안 노이즈 캔슬러 (Trust Anchor & Anti-BS - C1/A1/E1 공통)**
    - **구현 목표:** 생성된 요약문의 모든 문장 끝에 **'원본 딥링크'**를 강제 매핑하여 1초 팩트체크를 보장하고, 서버 전송 전 주민번호/기밀 키워드를 가리는 **'마스킹 파이프라인'** 탑재. 부가적으로 절감된 인건비를 보여주는 **'ROI 리포트'** 제공.
    - **전략 의미:** B2B 기업들이 AI 도입 시 가장 두려워하는 두 가지 요소(AI의 거짓말, 내부 기밀 유출)를 원천 차단하여 결재권자를 무장해제시키고, "완벽히 안전한 엔터프라이즈급 에이전트"라는 포지셔닝을 확립합니다.
